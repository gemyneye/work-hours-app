# Work Hours Tracking Application

## Overview

This project was created to provide a simple way to add a work schedule, track hours worked, and share scheduled shifts with a calendar.

It also serves as my first from-scratch web application project, giving me hands-on experience with designing, building, and structuring a web app.
This is a personal learning and portfolio project. I’m building it independently and am not currently accepting contributions.

## Development Goals

- Clear maintainable HTML structure
- Follow Pythonic PEP 8 and utilize tools learned

## Technologies Used

- Flask
- Python
- Git and GitHub
- VS Code
- Command Line Interface

### User Stories

1. Provide way to input the date
2. User can input start time and end time
3. Date and time will update selected Calendar on iPhone (Future feature)
4. Provide an Edit button to adjust date and time
5. Edit date/time will update the Calendar entry on iPhone (Future feature)fit
6. App will calculate totals daily and per pay period

### Overall Settings
1. Set up Pay Period Start Date
2. Set up Hourly Pay Rate
3. Option: Set up tax rate withholding
